# Проверка результатов

Проверка результата запуска начинается с `Новый ПроверкаРезультатаБенчмарков(Результат)`. Методы образуют цепочку: сначала ограничьте выборку кейсов, затем выберите метрику и задайте условие.

```bsl
Проверка = Новый ПроверкаРезультатаБенчмарков(Результат)
    .ОтборБенчмарка("Сортировка")
    .ОтборПараметра("Размер", 1000)
    .Метрика(МетрикиБенчмарков.Минимум())
    .Больше(0)
    .МеньшеИлиРавно(0.3);
```

Без отборов в выборку попадают все кейсы результата. Несколько значений одного отбора объединяются через `ИЛИ`: например, два вызова `ОтборБенчмарка` выберут любой из указанных методов. Для `ОтборПараметра` группой является имя параметра: значения одного параметра объединяются через `ИЛИ`, а отборы разных параметров — через `И`. `ОтборЭталонных` оставляет только эталонные кейсы. Отборы разных групп объединяются через `И`: одновременно учитываются метод, категория, параметры, идентификатор, версия среды и признак эталона.

Неизвестное имя параметра вызывает исключение. Если отборы не выбрали ни одного кейса, вызов `Метрика` также завершается исключением. После `Метрика` значения фиксируются в объекте проверки метрики; последующие отборы результата к нему не применяются.

Один вызов проверки метрики проверяет все выбранные кейсы. При нарушениях исключение содержит все нарушившие кейсы, а не только первый.

Для границ используются включительные условия: `МеньшеИлиРавно` означает `<=`, `БольшеИлиРавно` — `>=`, `Между` включает обе границы. `Около` проверяет абсолютное отклонение, не превышающее допуск.

Подробности API: [ПроверкаРезультатаБенчмарков](api/ПроверкаРезультатаБенчмарков.md), [ПроверкаМетрикиБенчмарков](api/ПроверкаМетрикиБенчмарков.md).
