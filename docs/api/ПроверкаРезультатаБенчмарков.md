# ПроверкаРезультатаБенчмарков

Отбирает кейсы результата запуска и передаёт значения выбранной метрики в [ПроверкаМетрикиБенчмарков](ПроверкаМетрикиБенчмарков.md).

## Синтаксис:

```bsl
Новый ПроверкаРезультатаБенчмарков(<Результат>)
```

**Параметры:**

| Имя | Тип | Описание |
| -- | -- | -- |
| Результат | [РезультатЗапускаБенчмарков](РезультатЗапускаБенчмарков.md) | Результат запуска для проверки. |

## Метрика

**Синтаксис:**

```bsl
Метрика(<Метрика>, [<ЕдиницаИзмерения>])
```

**Параметры:**

| Имя | Тип | Значение по умолчанию | Описание |
| -- | -- | -- | -- |
| Метрика | Строка |  | Идентификатор из [МетрикиБенчмарков](МетрикиБенчмарков.md). |
| ЕдиницаИзмерения | [ЕдиницаИзмеренияБенчмарка](ЕдиницаИзмеренияБенчмарка.md), Неопределено | `Неопределено` | Целевая единица измерения. |

**Возвращаемое значение:**

Тип: [ПроверкаМетрикиБенчмарков](ПроверкаМетрикиБенчмарков.md).

**Описание:**

Извлекает метрику для всех выбранных кейсов и при необходимости конвертирует её в совместимую единицу. Если кейсы не выбраны или метрика недоступна хотя бы для одного из них, вызывает исключение.

## Правила отбора

Без отборов выбираются все кейсы. Повторные вызовы одного отбора объединяются через `ИЛИ`, разные отборы — через `И`. У `ОтборПараметра` группой служит имя параметра: значения одного параметра объединяются через `ИЛИ`, отборы разных параметров — через `И`.
