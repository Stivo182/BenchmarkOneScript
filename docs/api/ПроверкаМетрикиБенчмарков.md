# ПроверкаМетрикиБенчмарков

Проверяет значения выбранной метрики для всех отобранных кейсов. При нарушении условия вызывает исключение со всеми нарушившими кейсами.

## Методы

[Равно](#равно) </br>
[Меньше](#меньше) </br>
[Больше](#больше) </br>
[МеньшеИлиРавно](#меньшеилиравно) </br>
[БольшеИлиРавно](#большеилиравно) </br>
[Между](#между) </br>
[Около](#около)

## Равно

**Синтаксис:**

```bsl
Равно(<Значение>)
```

**Параметры:**

| Имя | Тип | Описание |
| -- | -- | -- |
| Значение | Число | Ожидаемое значение. |

**Возвращаемое значение:**

Тип: [ПроверкаМетрикиБенчмарков](ПроверкаМетрикиБенчмарков.md).

**Описание:**

Проверяет равенство фактического значения ожидаемому.
