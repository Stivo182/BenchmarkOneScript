## Минимум

**Синтаксис:**


## Процентиль

**Синтаксис:**

```bsl

```

**Параметры:**

| Имя | Тип | Описание |
| -- | -- | -- |
| Значение | Число | Процентиль от 0 до 100. |

**Возвращаемое значение:**

Тип: Строка.

**Описание:**

Возвращает идентификатор метрики указанного процентиля.
