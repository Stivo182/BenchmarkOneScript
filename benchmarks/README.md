# Бенчмарки BenchmarkOneScript

Каталог содержит короткий набор бенчмарков для контроля накладных расходов и масштабируемости самой библиотеки.

## Состав

- [БенчмаркНакладныхРасходов](БенчмаркНакладныхРасходов.os) — нижняя граница измерений на пустом и контролируемом методах.
- [БенчмаркХолодногоЗапуска](БенчмаркХолодногоЗапуска.os) — первый вызов пустого метода в изолированном процессе.
- [БенчмаркГенерацииКейсов](БенчмаркГенерацииКейсов.os) — комбинирование параметров и создание кейсов.
- [БенчмаркПостроенияОтчета](БенчмаркПостроенияОтчета.os) — построение отчёта при росте числа кейсов.
- [БенчмаркРасчетаСтатистики](БенчмаркРасчетаСтатистики.os) — расчёт среднего, квартилей, отклонения и других показателей.
- [БенчмаркОтносительнойСтатистики](БенчмаркОтносительнойСтатистики.os) — расчёт отношений замеров бенчмарка и эталона.
- [БенчмаркСериализацииРезультатов](БенчмаркСериализацииРезультатов.os) — преобразование результатов в JSON и обратно.

## Запуск

Весь набор:

```bash
becnhos run ./benchmarks
```

Отдельный бенчмарк:

```bash
becnhos run ./benchmarks/БенчмаркНакладныхРасходов.os
```
