# Бенчмарки BenchmarkOneScript

Каталог содержит короткий набор бенчмарков для контроля накладных расходов и масштабируемости самой библиотеки.

## Состав

- `БенчмаркОтносительнойСтатистики.os` — расчёт отношений замеров бенчмарка и эталона.
- `БенчмаркГенерацииКейсов.os` — комбинирование параметров и создание кейсов.
- `БенчмаркРасчетаСтатистики.os` — расчёт среднего, квартилей, отклонения и других показателей.
- `БенчмаркПостроенияОтчета.os` — построение отчёта при росте числа кейсов.
- `БенчмаркСериализацииРезультатов.os` — преобразование результатов в JSON и обратно.
- `БенчмаркНакладныхРасходов.os` — нижняя граница измерений на пустом и контролируемом методах.
- `БенчмаркХолодногоЗапуска.os` — первый вызов пустого метода в изолированном процессе.

## Устройство бенчмарков

Все файлы бенчмарков находятся непосредственно в этом каталоге. Каталог не содержит вспомогательных сценариев и подкаталогов.

Входные данные создаются в обработчиках `&ПередКаждымКейсом`. В измеряемом методе остаётся только целевая операция. Для тяжёлых сценариев задаётся один вызов за итерацию.

Параметры ограничены коротким профилем: до 100 отношений замеров, 1 000 кейсов и строк отчёта, 10 000 замеров для расчёта статистики.

## Запуск

Весь набор:

```bash
oscript src/BenchmarkOneScript/cmd/main.os run benchmarks
```

Отдельный бенчмарк:

```bash
oscript src/BenchmarkOneScript/cmd/main.os run benchmarks/БенчмаркРасчетаСтатистики.os
```

В результатах не проверяются жёсткие абсолютные пороги времени. Сравнивать прогоны следует только в одинаковом окружении.
